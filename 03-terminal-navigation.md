# Assignment 03 — Terminal navigation practice

Example commands (run them in your own terminal):

```bash
pwd
ls
mkdir html-css-practice
cd html-css-practice
touch index.html
ls -la
cd ..
```

| Command | Purpose |
|---|---|
| `pwd` | Shows the current working directory |
| `ls` | Lists files and folders (use `dir` in Windows Command Prompt) |
| `mkdir name` | Creates a directory |
| `cd name` | Moves into a directory |
| `cd ..` | Moves up one directory |
| `touch file.html` | Creates an empty file on macOS/Linux/Git Bash |
| `dir` | Lists items in Windows Command Prompt |
